## 2.2 How to verify an admin?  
Ask for a wallet ownership test (e.g., send 2000 e → return 1000 e).

## 2.3 How to identify scams?  
- Refuses wallet verification  
- No transaction history  
- No contribution records  
- Promises profits

Check Solscan for transaction history.

## 2.5 How to verify actual contribution?

Yes—share evidence in the community.

## 2.10 Does EACO guarantee price?
